# Exploratory Data Analysis (EDA) Project Report

## Introduction

Exploratory Data Analysis (EDA) is used to understand datasets through statistical summaries and visualizations.

## Objective

To analyze sales data and identify patterns, trends, and influencing factors.

## Dataset

The dataset contains:

- Product
- Category
- Sales
- Profit

## Methodology

1. Data Collection
2. Data Cleaning
3. Statistical Summary
4. Correlation Analysis
5. Data Visualization
6. Insight Generation

## Statistical Analysis

Average Sales: 22300

Average Profit: 4350

Maximum Sales: 50000

Minimum Sales: 5000

## Correlation Analysis

Sales and Profit correlation = 0.99

This indicates a strong positive relationship.

## Insights

- Electronics category has highest sales.
- Laptop is the top-performing product.
- Stationery contributes the least revenue.
- Higher sales generally result in higher profits.

## Conclusion

EDA successfully revealed business trends and important factors affecting sales performance.
